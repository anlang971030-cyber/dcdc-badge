# 标识牌生成器整合版

本地预览：http://127.0.0.1:8765/ （服务运行期间可访问）。

## 使用

1. 填写姓名、岗位、部门及专业方向，进入制作方式选择。
2. 人格模式：完成原有六题，选择眼镜和兴趣，生成标识牌。
3. 图片模式：上传图片，选择字符预设、自定义中文／英文／代码和颜色；高级设置内可调整列数、字号、行高、透明阈值及反相。修改参数后点击“应用效果”。
4. 可并排查看原图与字符画，下载透明字符画 PNG，或生成标识牌并查看大图、下载 2000×900 PNG。
5. 返回制作方式即可切换分支；个人信息保留，当前页面内的图片及人格选择也会保留。刷新页面后需重新上传图片。

## 静态发布包

`badge-static-release.zip` 内的 `index.html` 直接位于 ZIP 根目录。解压后的全部内容可放到 GitHub 仓库根目录；不需要构建、不需要安装依赖或后台。此次没有上传 GitHub，也没有修改线上网站。

独立工作副本为同目录的 `badge-static` 文件夹。原始两个 ZIP 保留不变，工作区开始时没有可供合并的后续修改版。历史目录、Java、Vue、node_modules、target 和托管配置未纳入发布包。

请通过 HTTP 静态服务访问，不能直接双击 HTML 使用 ES 模块。安装了 Python 的电脑可在解压目录执行 `python -m http.server 8765 --bind 127.0.0.1`。

## 实现与限制

- 保持原生 HTML/CSS/JavaScript。`ascii/ascii-canvas.js` 移植三份 Java 源码的字符池、灰度采样、背景估计、透明阈值、颜色及透明裁边逻辑；默认参数与队友前端和 Java 配置一致。
- 中文使用系统字体回退，并适配字符单元宽度；浏览器与 Java 字体栅格化有合理差异。透明裁边会去除外围空白，主体等比放入右侧区域。
- 两种标识牌共用 `assets/template-base.png`、`textLayout()` 和原有文字绘制参数。图片模式不显示人格中英文，也不编造人格；界面文案集中在 `ascii/ascii-canvas.js` 的 `COPY`。
- 图片完全在浏览器处理，无外部 API、无 AI 抠图。支持 PNG、JPEG、WebP、GIF、BMP；GIF 仅使用静态帧。
- 文件最大 20 MB、输入最多 4000 万像素，处理最长边 1600 px；输出字符画最多 800 万像素、单边 8192 px。过大参数、无效文件和全透明结果会提示。极大原图解码仍依赖设备内存。
- 原图对象 URL 在解码后释放，替换图片／效果时释放旧资源，离开页面时清理下载 URL。

## 验证

已在本机 Microsoft Edge 实测：原六题流程、眼镜与兴趣选择、双分支返回切换、信息保留、中文自定义字符、四种预设与颜色模式、并排对比、大图和两类 PNG 下载。

两种标识牌均为 2000×900；左侧姓名／部门方向／岗位区域像素一致。字符画保持透明并等比放置。390 px 手机视口无横向溢出，已检查页面截图。

根目录流程通过；仓库子路径 `/badge-static/` 下两种合成通过，105 个静态资源全部返回 200。验证期间无页面 JavaScript 异常。损坏图片、全透明结果和超限输出均已检查。

未实测微信、iOS Safari 或实体手机；移动端下载／长按保存行为及字体可能因系统而异。未进行线上部署测试。
